# YK Pao School – Yau Tseng Class Announcement (April Fools’ Edition)

This project contains two HTML files that mimic an official school news announcement: **YK Pao School to launch the Yau Tseng Class in the 2026–27 academic year**.  

The pages are styled exactly like real YK Pao School news articles and include a language switcher between Chinese and English versions.

---

## ⚠️ Important Disclaimer

**This is an April Fools’ Day joke created for entertainment purposes only.**  
The announcement is **completely fictional**.  

- The Yau Tseng Class mentioned in the text does **not** exist at YK Pao School.  
- No such program has been authorized or announced.  
- The dates, quotes, and all details are invented.  

**Do not take this seriously or treat it as real news.**  

If you are a visitor who found this online: please check the official YK Pao School website for accurate information.

---

## How to Use

1. Place both HTML files and the `_files` folder in the same directory.
2. Open either HTML file in a modern web browser.
3. Click the **“En”** (English) or **“中文”** button to switch between the two versions.

> The language buttons are set to link to the respective file names. If you rename the files, update the `href` attributes accordingly.

---

## Technical Notes

- The pages reuse the original stylesheets and assets from the live YK Pao School website (included in the `_files` folder). They are only used to maintain a consistent look.
- No backend functionality is required; the page is static.
- The “view count” displayed is a static placeholder and does not track actual visitors.
